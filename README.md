# HCLTech Technical Assessment

A technical assessment focused on **SQL, Linux, PySpark, AWS, and Microsoft Azure**, covering database querying, data processing, cloud infrastructure, security, automation, and troubleshooting.

## Overview

This assessment demonstrates technical knowledge of data engineering concepts and cloud technologies through practical problem-solving scenarios, SQL queries, scripting tasks, data transformation operations, and cloud architecture design.

## Technical Domains

### Advanced SQL
- Joins and relational database queries
- Subqueries and department-wise salary analysis
- Window functions and employee ranking
- Sales analytics and revenue calculations
- Indexing strategies and query optimization
- Execution plans and duplicate detection

### Linux Administration
- Log analysis using `grep`, `awk`, and `tail`
- File and directory permissions
- Process, memory, and disk monitoring
- Error tracking and log extraction
- Bash scripting and automated backups

### PySpark Data Engineering
- DataFrame creation and schema definition
- Filtering, sorting, and column transformations
- Grouping and aggregation
- Handling missing values, duplicates, and invalid dates
- Customer and order dataset joins
- Revenue calculations and data processing optimization

### AWS Cloud Services
- Amazon S3 storage and access security
- AWS IAM policies and least-privilege access
- Amazon EC2 troubleshooting
- Amazon CloudWatch monitoring and alarms
- AWS Lambda and event-driven processing
- AWS Step Functions workflow orchestration
- Error handling, retries, and execution monitoring

### Microsoft Azure
- Azure Data Lake Storage Gen2
- Hierarchical namespace and storage organization
- Microsoft Entra ID and Azure RBAC
- Azure Virtual Machine troubleshooting
- Azure Data Factory pipelines and data ingestion
- Data quality validation and error handling
- Pipeline monitoring and data completeness checks

## Key Skills Demonstrated

`SQL` · `Linux` · `Bash Scripting` · `Python` · `PySpark` · `Data Cleaning` · `Data Transformation` · `AWS` · `Azure` · `ETL` · `Cloud Security` · `Workflow Automation` · `Troubleshooting`

## Learning Outcomes

- Apply SQL techniques to relational data analysis and query optimization.
- Perform data cleaning, transformation, and aggregation using PySpark.
- Automate system operations and analyze application logs in Linux.
- Understand cloud storage security, access management, and monitoring.
- Design automated, event-driven data processing workflows.
- Understand data ingestion and orchestration using Azure Data Factory.
